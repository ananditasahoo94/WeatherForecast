# 🌤️ Weather Forecast App

A responsive and user-friendly weather forecast application built using **HTML**, **CSS**, and **JavaScript**, powered by the [OpenWeatherMap API](https://openweathermap.org/api). Users can search for any city to view current weather conditions, today's weather highlights, and a 5-day forecast.

## 🚀 Features

- 🔍 **Search by City Name**
- 🌡️ **Temperature Unit Toggle** – Switch between Celsius (°C) and Fahrenheit (°F)
- 🌥️ **Current Weather Display** – Temperature, description, icon, and feels like
- 📆 **Date & Time** – Adjusted for city's local timezone
- 🌤️ **Today's Highlights**:
  - Humidity
  - Wind Speed
  - Cloud Coverage
  - Sunrise / Sunset
  - Pressure
- 📅 **5-Day Forecast** – Displays forecast for the next 5 days (first entry per day)
- 📱 **Responsive Design** – Works smoothly on all screen sizes

## ⚙️ How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/ananditasahoo94/WeatherForecast.git
   cd WeatherForecast
````

2. Open `index.js` and replace the API key with your own from [OpenWeatherMap](https://openweathermap.org/):

   ```js
   const API_KEY = "your_api_key_here";
   ```

3. Open `index.html` in your browser.

---

## 📡 API References

* **Current Weather API**:
  `https://api.openweathermap.org/data/2.5/weather`
* **Forecast API (5-day)**:
  `https://api.openweathermap.org/data/2.5/forecast`

*Parameters:*

* `q` → city name
* `appid` → your API key
* `units` → `metric` for °C or `imperial` for °F
